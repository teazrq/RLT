# Quantile Forest (Not Yet Implemented)

Internal function for fitting quantile regression forest. This feature
is not yet implemented. Calling
[`RLT()`](https://teazrq.github.io/RLT/reference/RLT.md) with
`model = "quantile"` will produce an informative error.

## Usage

``` r
QuanForest(x, y, ncat, obs.w, var.prob, resample.preset, param, ...)
```
