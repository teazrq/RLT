# Print a single tree

Print a single fitted tree from a forest object

## Usage

``` r
get.one.tree(x, tree = 1, ...)
```

## Arguments

- x:

  A fitted RLT object

- tree:

  the tree number, starting from 1 to `ntrees`.

- ...:

  ...

## Examples

  y <- rowSums(x[, 1:2]) + rnorm(300)

  get.one.tree(fit, tree = 1)
